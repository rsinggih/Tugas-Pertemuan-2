Tentang Saya

Halo, saya Singgih, mahasiswa program studi Teknologi Informasi di Universitas Muhammadiyah Purworejo. Sambil kuliah, saya bekerja sebagai petugas lapangan di Perum BULOG yang ikut menangani penyaluran bantuan pangan.

Dari pekerjaan itu saya jadi tertarik dengan pengelolaan dan validasi data, dan ingin belajar membuat aplikasi web yang bisa membantu kerja di lapangan. Halaman ini adalah latihan HTML saya.
